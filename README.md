# Personal Portfolio — Kareem Nasrallah

A responsive personal portfolio showcasing my front-end development skills, work experience, projects, and technical expertise. The website features interactive animations, customizable color themes, and light and dark modes to create a personalized browsing experience.

## 🌐 Live Demo

[View My Portfolio](https://k-nasrallah-portfolio.vercel.app/)

## ✨ Features

- **Six Main Pages:** Home, About, Work Experience, Portfolio, Skills, and Contact.
- **Customizable Color Themes:** Switch between blue, green, orange, and purple color palettes, with multiple shades available for each theme.
- **Light and Dark Modes:** Toggle between light and dark appearances.
- **Interactive Skills Section:**
  - Animated circular rotation of skill icons.
  - Click on any skill icon to view information about the technology.
  - Filter skills by category using dedicated controls.
- **Animated Hero Text:** A looping text-fill animation for the "Front-End Developer" heading, alternating between filled text and outlined lettering.
- **Page Entrance Animations:** Animated transitions and visual effects when entering pages.
- **Responsive Design:** Layouts adapt to different screen sizes, including desktop, tablet, and mobile devices.
- **Interactive Portfolio:** A project showcase with category-based filtering.
- **Custom Styling:** Page-specific stylesheets and global CSS for layout, typography, animations, and visual consistency.

## 🛠️ Technologies Used

- **React** — Component-based user interface development.
- **Vite** — Development server and production build tooling.
- **Redux Toolkit** — Centralized state management.
- **React Router DOM** — Client-side routing between pages.
- **Tailwind CSS** — Utility-first CSS framework.
- **MixItUp** — Animated filtering and sorting for portfolio items.
- **CSS3** — Custom styling, responsive layouts, transitions, and animations.

## 🎨 Styling Approach

The project originally used traditional CSS before Tailwind CSS was introduced into my workflow. As a result, the website maintains a hybrid styling approach:

- Global CSS files for shared styles and site-wide settings.
- Page-specific CSS files for individual layouts and components.
- CSS-based animations, transitions, and responsive adjustments.
- Tailwind CSS included in the project's technology stack, while subsequent updates and styling changes continued to rely primarily on the existing CSS structure.

This approach allowed me to extend and improve the original project while preserving its established styling system.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

### Production Build

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
